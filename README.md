# Text Summarizer App

A Blazor Server app to summarize long text into concise outputs, built with .NET, MudBlazor, and AI integration.

---

## Features
- **Text Input**: Paste or upload text for summarization.
- **Summarization Modes**: Choose from Short, Medium, or Detailed summaries.
- **AI Integration**: Uses AI models (e.g., OpenAI or Hugging Face) for high-quality text analysis.
- **History**: Save and review past summaries (optional).

---

## Tech Stack
- **Frontend**: Blazor Server with MudBlazor components.
- **Backend**: .NET 8 services using Dependency Injection.
- **Database**: SQL Server for storing summary history.

---

## How It Works
1. Enter your text or upload a file.
2. Select a summarization mode.
3. Click "Summarize" to generate the summary.
4. View the output or save it to history.

---

## Requirements
- .NET 8 SDK
- SQL Server
- API Key (e.g., OpenAI or Hugging Face)

---

## Deployment
- Host the app using Azure App Service.
- Use Azure SQL Database for history storage.
