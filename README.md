# Text Summarizer App

A Blazor Server app to turn long text into concise summaries using AI.

---

## Features
- **Summarize Text**: Paste text or upload files.
- **Modes**: Short, Medium, or Detailed summaries.
- **History**: Save and review past summaries.

---

## Tech Stack
- **Frontend**: Blazor Server + MudBlazor.
- **Backend**: .NET 8 with AI integration.
- **Database**: SQL Server for history.

---

## How to Use
1. Enter text or upload a file.
2. Select a summarization mode.
3. Click "Summarize" to get results.

---

## Deployment
- Host with Azure App Service.
- Use Azure SQL for storage.
